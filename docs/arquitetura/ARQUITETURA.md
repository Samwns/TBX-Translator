# TBX Translator — Architecture

> Last updated: August 02, 2026

## Overview

TBX Translator is a native desktop application for automated game translation. It extracts text from game engines (Ren'Py, Unity), translates via Google Translate API, and injects the translations back into the game.

Built entirely in **Rust** with **GTK4** for the UI — no web technologies, no Electron, no WebView.

## Why Native GTK4?

| Concern | Tauri/Electron | GTK4 (current) |
|---------|---------------|----------------|
| Runtime | Embedded Chromium/WebView | Native machine code |
| Binary size | ~80MB+ | ~5MB |
| RAM usage | ~200MB+ | ~30MB |
| Linux compatibility | Broken on Fedora (webkit2gtk issues) | Works everywhere |
| Styling | Web CSS (unpredictable rendering) | GTK CSS (native, consistent) |
| Build system | Node.js + NPM + Cargo | Cargo only |

## Module Reference

| Module | File | Size | Responsibility |
|--------|------|------|----------------|
| Entry Point | `main.rs` | 452B | GTK Application init |
| Main UI | `ui.rs` | 65KB | All windows, widgets, CSS, event handlers |
| Translation Editor | `editor_ui.rs` | 12KB | Manual edit UI for `.rpy`/`.txt`/`.json` |

| API Client | `api.rs` | 3.3KB | Google Translate HTTP calls |
| Config | `app_config.rs` | 5.2KB | JSON settings persistence |
| Ren'Py Engine | `renpy_extractor.rs` | 11KB | Python injection, dump parsing, .rpy generation |
| Unity Engine | `unity_extractor.rs` | 18KB | C# bridge, BepInEx install, config management |

| Python Script | `desired_python.py` | 8.1KB | Injected into Ren'Py games for text dump |
| C# Extractor | `Program.cs` | 29KB | Unity asset reading via AssetsTools.NET |

## Data Flow

### Ren'Py Pipeline
```
Game .exe → inject desired_python.py → headless run (xvfb) → dump.txt
→ parse & filter → protect variables ({b}→777001777)
→ batch translate (Google API) → restore variables
→ generate .rpy translation files → done
```

### Unity Pipeline
```
Game Data/ → dotnet run Program.cs extract → extracted_texts.json
→ batch translate (Google API, protect {0}/{1}/tags)
→ translated_texts.json → generate _AutoGeneratedTranslations.txt
→ install BepInEx (local ZIP) → install XUnity AutoTranslator
→ update AutoTranslatorConfig.ini → copy dict to BepInEx/Translation/
→ done (game reads translations at runtime via XUnity)
```

## Build & Run

```bash

cargo run

# Release
cargo build --release
# Output: target/release/tbx-translator
```
